# Security policy

CatchThat is designed for local, read-only archive work. It must not receive
Snapchat credentials, cookies, browser storage, tokens, private API responses,
or live conversation data through an issue, pull request, log, or chat.

## Reporting a vulnerability

Please report security issues privately through a GitHub Security Advisory on
the CatchThat repository, or contact the repository owner through a private
channel before opening a public issue. Include reproduction steps, affected
files or versions, and the smallest safe synthetic example possible.

Do not attach real conversations, screenshots, browser exports, credentials,
or session material to a report. Redact any archive before sharing it and keep
raw captures under an access-controlled local path.

## Supported versions

The latest `main` release is the supported line. Security fixes are best
validated against the current release and the current default branch.
