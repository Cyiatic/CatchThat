# Changelog

All notable CatchThat changes are recorded here.

## 0.2.0 — 2026-08-27

- Added a repo-local, skills-only Codex plugin for the attended CatchThat
  workflow.
- Added portable ZIP import/export and optional password-protected AES-256-GCM
  bundles with safe extraction checks.
- Added a redacted-share PowerShell pipeline and a public-package validator.
- Added synthetic-only release packaging, CI checks, provenance safeguards,
  media/profile placeholder handling, and offline viewer verification.

## 0.1.0

- Initial local-first archive engine, visible-DOM capture adapter, normalized
  archive format, and offline viewer.
